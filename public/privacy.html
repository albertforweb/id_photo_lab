Privacy Policy

Last updated: 2026-08-20

Local Processing

ID Photo Lab is designed to process uploaded photos locally in your browser or desktop app by default. Uploaded photos are not sent to an ID Photo Lab server for editing, background removal, face detection, or export.

Files You Choose

The app reads image files only after you select or drop them into the editor. Exported files are created only when you choose a download action.

Network Access

Source builds may download model assets during development when running the asset vendor command. Packaged desktop builds include the required local model assets for background removal and face detection.

Analytics

The current app does not include analytics, tracking pixels, advertising SDKs, or account login.

Document Requirements

Document photo requirements can change. ID Photo Lab stores source names and checked dates, but users should verify final requirements with the issuing authority before submitting an official application.
